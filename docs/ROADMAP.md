# Risk//OS roadmap

## Current: reference release

- Explainable deterministic scoring
- Transaction review and investigation workflows
- D1 persistence and audit events
- Model-health and operational visibility
- Private authenticated deployment

## Next: controlled pilot

- Tenant isolation and role-based access control
- Idempotent event ingestion and durable rate limiting
- Queue ownership, service-level timers, and escalation policies
- OpenTelemetry traces, structured logs, alerting, and SIEM export
- Expanded API integration and end-to-end test coverage

## Later: regulated production

- Tokenized payment-provider integration
- Formal model registry, approval workflow, and champion/challenger deployment
- Calibration, fairness, drift, and adverse-action validation
- Retention, legal hold, privacy rights, and regional data controls
- Load, penetration, disaster-recovery, and failover certification

Roadmap items are directional and are not commitments to a release date.
